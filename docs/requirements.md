# 需求分析文档

**项目名称**：PokeMe — 动物图鉴  
**版本**：v1.0  
**日期**：2026-04-13  

---

## 一、产品定位

### 1.1 产品愿景

打造一款「动物图鉴」——用户用摄像头对准任何动物，AI 立刻生成游戏风格的图鉴卡片，记录并收藏遇到的动物。

### 1.2 v1.0 范围说明

> 本版本**只识别动物**，包括：
> - 家养宠物（猫、狗、鸟、鱼等）
> - 野生动物（昆虫、鸟类、爬行类等）
> - 动物园动物
> - 动物图片/照片/卡片（对着书本或屏幕上的动物图也可以扫）
>
> 非动物图片将返回提示，引导用户重新扫描。

### 1.3 目标用户

| 用户群体 | 使用场景 | 核心需求 |
|---------|---------|---------|
| 好奇心强的成年人 | 户外探索、旅行、动物园 | 了解动物知识 |
| 儿童（6-12岁） | 户外活动、学习 | 学习动物知识、收集乐趣 |
| 动物爱好者 | 日常观察 | 识别不认识的动物 |

### 1.4 产品形态演进

```
v1.0（当前）：动物图鉴 Web App
    ↓
v2.0：扩展至万物识别
    ↓
v3.0：PWA 移动端 + 实体打印卡片
    ↓
v4.0：实体硬件设备（树莓派 + 打印机）
```

## 二、功能需求

### 2.1 核心功能（MVP）

#### F01 — 摄像头拍照
- 用户打开网页，自动请求摄像头权限
- 实时预览摄像头画面
- 点击快门按钮拍照
- 支持上传本地图片（备用方案）
- 移动端优先使用后置摄像头

#### F02 — AI 动物识别
- 将拍摄图片发送给 Claude Vision API
- AI 判断图中是否有动物
  - 无动物：返回提示「未发现动物，请重新扫描」
  - 有动物：生成完整图鉴条目
- 图鉴条目包含以下字段：

| 字段 | 说明 | 示例 |
|------|------|------|
| number | 图鉴编号（4位） | "0042" |
| name | 动物中文名 | "橘猫" |
| scientific_name | 学名 | "Felis catus" |
| category | 动物类别 | "哺乳动物" |
| height | 估算体型 | "0.3m" |
| weight | 估算体重 | "4.5kg" |
| habitat | 栖息地 | "人类居所、温带地区" |
| diet | 食性 | "肉食性，以鱼类、小鼠为主" |
| predator | 天敌 | "大型犬科动物" |
| conservation | 保护状态 | "无危 (LC)" |
| description | 图鉴描述（50字内，拟人有趣） | "慵懒的室内霸主..." |
| rarity | 稀有度 | "普通" |
| attributes | 属性标签（2-3个） | ["毛茸茸", "夜行", "独行"] |

#### F03 — 图鉴卡片展示
- 以游戏图鉴风格展示识别结果
- 包含扫描照片缩略图
- 动画效果：卡片从底部滑入 + 描述打字机效果
- 稀有度对应不同视觉风格

#### F04 — 收藏图鉴
- 每次识别结果自动存入本地数据库
- 图鉴列表页：展示所有已发现动物
- 支持按类别筛选（哺乳动物/鸟类/昆虫等）
- 显示收集总数

### 2.2 游戏化功能

#### F05 — 稀有度系统

稀有度由 AI 根据动物的**真实濒危程度 + 常见程度**判定：

| 稀有度 | 对应标准 | 视觉效果 |
|--------|---------|---------|
| 普通 | 常见家养/城市动物 | 白色边框 |
| 稀有 | 不常见野生动物 | 蓝色边框 + 光效 |
| 极稀有 | 易危/濒危物种 | 紫色边框 + 光效 |
| 传说 | 极危/野外灭绝物种 | 金色边框 + 特殊动画 |

#### F06 — 首次发现提示
- 首次扫描到某种动物：触发「新动物发现！」动画
- 已扫描过的同种动物：显示「又遇见了」，直接读取缓存

#### F07 — 收集统计
- 已发现动物总数
- 各类别数量分布
- 最近发现记录

### 2.3 非功能需求

| 需求 | 指标 |
|------|------|
| 识别响应时间 | ≤ 5秒 |
| 页面加载时间 | ≤ 2秒 |
| 移动端适配 | 支持手机浏览器 |
| 摄像头兼容性 | Chrome / Safari / Edge |
| 数据持久化 | 本地 SQLite |

## 三、不做什么（范围边界）

- ❌ 不识别非动物物体（v1.0）
- ❌ 不做用户账号系统
- ❌ 不做多人联网功能
- ❌ 不做实体打印（后续版本）
- ❌ 不做离线 AI 识别
- ❌ 不做 App Store 上架

## 四、用户流程

```
打开网页
    ↓
摄像头预览画面
    ↓
对准动物，按快门
    ↓
扫描动画（等待 AI，约 3-5 秒）
    ↓
[识别到动物]
    ↓
  ├─ [首次发现] → 「新动物发现！」动画 → 图鉴卡片展示
  └─ [已发现过] → 「又遇见了」→ 图鉴卡片展示（读缓存）
    ↓
[未识别到动物] → 「未发现动物，请重新扫描」提示
    ↓
可选：查看收藏图鉴
```

## 五、界面设计要求

### 5.1 整体风格
- 参考宝可梦图鉴：红色主题、圆角卡片
- 深色背景 + 高亮卡片
- 移动端优先

### 5.2 主要页面

| 页面 | 说明 |
|------|------|
| 扫描页（/） | 摄像头预览 + 快门按钮 |
| 结果页 | 图鉴卡片，可返回继续扫描 |
| 图鉴页（/collection） | 已发现动物列表，网格布局 |

## 六、技术约束

- 后端语言：Python 3.10+
- AI 服务：Anthropic Claude API（claude-opus-4-6）
- 数据存储：SQLite（本地文件）
- 部署：Railway（自动 HTTPS）
